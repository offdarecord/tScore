# Security policy

## Supported versions

Only the latest stable release receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for a security problem.

Report it privately through GitHub: on the repository page, go to **Security → Report a
vulnerability**. Include the tScore version, what you found, and how to reproduce it.
Leave out real rider data.

We aim to acknowledge reports within 7 days. tScore is maintained by volunteers, so please
allow reasonable time for a fix before disclosing publicly.
