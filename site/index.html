Free scoring for motorcycle trials, built for club volunteers.

tScore is a Windows app (Mac coming soon!) for the scoring desk. It works with no internet at the venue, reads riders' punched scorecards with a cheap USB document camera, and turns them into ranked results.

Download for Windows Take the tour

Free and open source. Windows 10 and 11. Early version: try it at home before you use it at an event.

What it does

  • Before the event

    Set up classes, sections and laps. Import the entry list from:

    • Ridernet
    • Entryplace
    • the tScore rider-list template, for any other list (download a sample CSV)

    Print card labels with a QR code for every rider and lap.

  • On the day

    Put each card under the camera: clear cards save themselves, anything unclear goes to a review queue with its photo. Or type cards in, keyboard only. See who is still on course at a glance.

  • Results

    Results build up as cards come in, ranked with the usual tie-breaks. Save a PDF with your club and sponsor logos, put live scores on a big screen, and keep series points across the season.

  • Safe with your data

    Everything stays on the laptop. Every change is saved at once, with automatic backups and an optional copy on a USB stick. Every score traces back to a card photo and an audit log.

Download and install

  1. Download the latest installer from the release page.
  2. Run it. tScore installs for you only, with no administrator password, and starts.
  3. If Windows shows Windows protected your PC, choose More info, then Run anyway. This goes once the installer is signed.
  4. Read Getting started, and try it at home with internet before the event. On the day it needs no internet.

tScore updates itself from GitHub when the laptop is online and no event is open. To remove it: Windows Settings → Apps → tScore → Uninstall. Your events stay in Documents\tScore.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Only the tScore app and its installer, built by this project's release workflow on GitHub Actions from the public source code, are signed, and every release is approved by hand.

  • Committers and reviewers: contributors with write access
  • Approvers: the repository owner

The full policy: CODE_SIGNING_POLICY.md.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it, with one exception: when the laptop is online and no event is open, tScore asks GitHub whether a newer version exists, and downloads it if so. tScore never sends event data, rider data or files anywhere.

This website uses no cookies and no tracking.
