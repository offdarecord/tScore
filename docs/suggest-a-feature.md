# Suggest a feature

Ideas from the people who run events are how tScore gets better. You don't need a GitHub
account.

## The easy way: in tScore

Open **About**, then **Suggest a feature**. Answer the questions, then choose **Email**,
**Copy** or **Save as file**. It works without internet: save it and send it later. tScore adds
only its version, the Windows version and which screen you were on. It never adds event or rider
details.

## Without tScore

Copy the questions below into an email to **tscoreapp@outlook.com**, or, if you have a GitHub
account, use the [feature request form](https://github.com/offdarecord/tScore/issues/new?template=feature_request.yml).

1. **In a few words, what would you like?** (required)
2. **What do you do at events?** (required)
   Choose one: Results desk / Club secretary / Clerk of Course / Observer / Rider / Other.
3. **What happens today, and what's hard about it?** (required)
   How do you get round it now?
4. **What would you like tScore to do instead?** (optional)
5. **How would you know it's working?** (required)
   Describe the moment at an event when it pays off.
6. **What should it not do?** (optional)
   Anything that would make it worse, or that's out of scope.
7. **When does it matter?** (optional)
   Choose one: Before the event / On the day / After the event (results and publishing).
8. **How much would it help?** (optional)
   Choose one: Nice to have / Saves time every event / We can't run our event without it.
9. **Example or picture** (optional)
   Describe it, or attach a photo of a paper form or a screenshot to your email or issue. Please hide riders' names and details.
10. **Can we contact you about it?** (optional)
   Name and club. Removed before anything is made public.

Please don't include riders' names, licence numbers or contact details, and hide them in any
photo.
