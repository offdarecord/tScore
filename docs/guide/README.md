# tScore user guide

tScore scores motorcycle trials on a Windows laptop, with no internet needed. This guide is for
the volunteers who run the results desk. In tScore, press **F1** or choose **Help** at the top
of any screen to open the page for that screen.

## Pages

1. [Getting started](getting-started.md): install tScore, find your way around, where your
   events are kept, and how to delete an old one.
2. [Before the event](before-the-event.md): event setup, the entry list, rider numbers, card
   labels and the pre-event check.
3. [Event day](event-day.md): typing in cards, penalties, late entries, DNF and DNS, and who is
   still on course.
4. [Results](results.md): provisional and final results, ties, and saving a PDF or CSV.
5. [Backups and restore](backups.md): what is saved, where, and how to get an event back.
6. [Event-day checklist](checklist.md): one page to print and take to the venue.
7. [Troubleshooting](troubleshooting.md): common problems, and how to get help.
8. [Error codes](errors.md): what each error code means and what to do.
9. [Glossary](glossary.md): trials and tScore words.

> [!NOTE]
> Scanning punched cards with a document camera is coming in a later version. Until then, cards
> are typed in on **Manual entry**, which is quick with the keyboard.
