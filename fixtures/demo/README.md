# Demo event

An invented club trial for screenshots, the feature tour and training: made-up riders, clubs
and scores, never a real person. `npm run screenshots` builds it in a throwaway folder and
captures each main screen into `docs/media/`.

- `riders.csv`: the entry list, in the tScore rider-list format.
- The scores are in [`apps/desktop/screenshots/tour.spec.ts`](../../apps/desktop/screenshots/tour.spec.ts).
