# tScore user guide

tScore scores motorcycle trials on a Windows laptop, with no internet needed. This guide is for
the volunteers who run the results desk. In tScore, press **F1** or choose **Help** at the top
of any screen to open the page for that screen.

## Pages

1. [Getting started](getting-started.md): what you need, install tScore, find your way around, and where your
   events are kept.
2. [Before the event](before-the-event.md): event setup, the entry list, rider numbers, card
   labels and the pre-event check.
3. [Event day](event-day.md): scanning and typing in cards, the review queue, penalties, late entries, DNF and DNS, and who is
   still on course.
4. [Results](results.md): provisional and final results, ties, and saving a PDF or CSV.
5. [Series points](series.md): a points tally across the rounds of a series, including a
   [series run by several clubs](series-across-clubs.md).
6. [Backups and restore](backups.md): what is saved, where, and how to get an event back.
7. [Event-day checklist](checklist.md): one page to print and take to the venue.
8. [Troubleshooting](troubleshooting.md): common problems, and how to get help.
9. [Error codes](errors.md): what each error code means and what to do.
10. [Try a test trial](test-trial.md): rehearse the whole day at home with the Test trial kit.
11. [Glossary](glossary.md): trials and tScore words.
12. [Card types](card-types.md): the scorecards tScore reads, and how to import or share your
    club's own.
