# Bringing tScore to your region

tScore is a free, open-source Windows app for scoring motorcycle trials. It imports your entry list, prints rider labels for the scorecards, reads punched cards with a cheap USB document camera, and produces results. It was built for clubs in Victoria, Australia. To support your region we need to see how _your_ events work.

This pack lists what to send. It takes about an hour to gather, most of it photographing cards. Example files showing the shape of each item are in the `examples/` folder that comes with this pack.

**Your files stay private.** They are used only to set tScore up for your region. Only anonymised test copies (names removed) ever go into the public project. Please only send files you are allowed to share. If you can, cover or blank rider names on card photos; we remove them again anyway.

**How to reply:** email **tscoreapp@outlook.com**. Answer the questionnaire however is easiest: type answers in the email, or print this, write on it and photograph it. Large files can go by any file-sharing link.

**Please don't send** dates of birth, addresses, phone numbers, medical or payment details. If your entry system's export includes them, that's fine: send it untouched and we'll make sure tScore never reads those columns. Just tell us so we can handle the file carefully.

## Card photo protocol

So we can teach tScore to read your cards:

1. **Lay each card on something matte black** (black card, cloth or a mouse mat). Holes then read black.
2. **Photograph from straight above**, in even light, no flash glare. Phone is fine. The whole card in frame, filling most of it.
3. **One card per photo.** Name files `card-01.jpg`, `card-02.jpg`, ….
4. **Write down the correct scores** for each card in a spreadsheet like `examples/card-truth-example.csv`: file name, rider number, lap, and the true score for each section. Mark anything odd: a corrected punch, a missed section, a torn card.
5. Photograph **one blank card** front and back, and measure its width and height in mm.
6. Tell us: does a rider get **one card per lap**, or **one card for the whole event**? Who punches it, when is it handed in, and how does an observer correct a wrong punch?
