# Event-day checklist

Print this page (**Print** at the top of the help panel) and take it to the venue.

## The week before

- [ ] Event setup done: dates, lap 1 start time, classes, sections and laps
- [ ] Entry list imported, and late changes made on **Riders**
- [ ] Card labels printed, and stuck on the cards for each lap
- [ ] tScore updated at home, with internet
- [ ] Laptop charged; charger packed

## Pack

- [ ] Laptop, charger, mouse
- [ ] USB stick for the second copy of backups
- [ ] Printer, paper and spare label sheets, if printing on the day
- [ ] Blank cards and labels for late entries
- [ ] This checklist

## On arrival

- [ ] Power on, and the laptop's date and time are right
- [ ] USB stick plugged in; **Saving and backup** shows the second copy
- [ ] **Pre-event check** run: nothing left to fix
- [ ] Late entries added on **Riders**, and their labels printed

## During the event

- [ ] Each card entered as it comes in, and the card kept in order
- [ ] **Progress** checked now and then for overdue riders
- [ ] Penalties added on **Manual entry**, with a reason

## Closing down

- [ ] **Still on course** shows everyone accounted for
- [ ] Results checked; provisional PDF pinned up for riders to check, if your club does
- [ ] Results marked final; final PDF and CSV saved
- [ ] Event closed (**← All events**); USB stick taken home
- [ ] Cards boxed and kept until results are settled

If something goes wrong, see [Troubleshooting](troubleshooting.md).
